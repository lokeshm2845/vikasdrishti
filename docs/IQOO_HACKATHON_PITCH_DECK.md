### Slide 2: Problem Statement
- **The Gap in Civic Governance:**
  1. **Connectivity Barriers:** Traditional web portals fail in low-network or offline municipal areas.
  2. **Language Divide:** Multi-lingual citizens struggle to file technical civic grievances.
  3. **Cloud Latency & Privacy:** Heavy cloud AI dependency causes delay and internet consumption.
- **Our Solution:** A 100% offline-resilient, AI-native platform running directly on the user's iQOO 15 device.

---

### Slide 3: Core Architecture – Phone-First & AI-Native
- **On-Device Storage Engine:** Local SQLite / IndexedDB for instantaneous zero-latency complaint creation.
- **Background Sync Engine:** Automatic bidirectional flush to Supabase when network is restored.
- **Snapdragon 8 Gen 3 NPU Power:**
  - **TFLite On-Device Categorization:** <50ms text/photo issue classification (pothole, streetlight, garbage).
  - **Bhashini Offline Models:** Local translation across 100+ Indian regional languages without cloud APIs.
  - **Offline Voice-to-Text:** Hands-free complaint entry in Hindi, Marathi, and English.

---

### Slide 4: Leveraging iQOO 15 Hardware
- **50MP High-Resolution Camera:** Auto client-side compression, EXIF coordinate verification, Before/After resolution proof comparison.
- **Dual-Frequency L1+L5 GPS:** Sub-meter accuracy for pinpointing exact street/gali locations.
- **Sub-10ms Geofencing Engine:** On-device Ray-Casting algorithm matching ward boundaries instantly on Snapdragon 8 Gen 3.

---

### Slide 5: "Red Light" Phase Readiness (iQOO Office Kit)
- **Built On-Device:** 100% executable and editable directly on the iQOO 15 phone using Termux + VS Code Web + iQOO Office Kit.
- **Zero Laptop Dependency:** Demonstrated full feature implementation during phone-only Red Light sessions.
